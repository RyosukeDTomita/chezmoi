# AGENTS.md

エージェント共通の規約。Claude / Codex などから参照される。

## Conventions

### sigma.md

ユーザの現在の理解を整理したファイルのため、誤りが多いため、エージェントは閲覧非推奨。

### Markdown

- mdの区切り文字（水平線）は `---` の3文字を使うこと。`___` や `***` は使わない。

### Document

- 実装を修正したら関連するドキュメントを必ず修正すること

### Language

- ユーザーへの応答は日本語で書くこと。英語で書かれたskill / ruleを読み込んだ場合も応答言語は日本語のままにする(コード・コマンド・識別子・引用はそのまま)。
