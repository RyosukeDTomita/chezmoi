# Daily Brief — 当日該当の定期タスク

その日 (JST 4時境界) に **該当する定期タスク** を提示する。

## 実行

```bash
bash "$CLAUDE_SKILL_DIR/daily-brief.sh"
```

env (任意):

| Var | 既定 | 意味 |
|-----|------|------|
| `CHECKLIST_URL` | ブログの checklist ページ | 定期タスクのチェックリスト URL |

スクリプトは 2 セクションを標準出力する:

- `=== DATE ===` … 論理日 (4時境界) と曜日
- `=== CHECKLIST ===` … チェックリストページの生 HTML

## 提示の手順

出力を元に、**日本語**で今日該当する定期タスクを提示する。

チェックリストは 3 セクション構成:

- **月始めにやること** … その月の初回起動日に該当
- **偶数月のはじめにやること** … 偶数月の初回起動日に該当
- **1年の終わりにやること** … 12 月に該当

**該当判定は、SessionStart フックが `additionalContext` で渡す「本日該当する定期タスクのセクション」を最優先する。**
フック経由 (自動) の場合はそこで指定されたセクションのみを抽出して提示する
(期間ごと初回のみ表示し重複を避けるため)。該当セクションが無い日はフックが無言で終了するため、
自動でブリーフィングが出ることはない。

手動実行でフックの指定が無い場合は、`=== DATE ===` の論理日から該当セクションを判断する
(月初回かどうかの dedup state はフックが管理するため、手動時は当日日付に対して素直に該当するものを示す)。
該当が無ければその旨を伝える。
